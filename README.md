# Out-n-About Bar and Music Lounge

Static, dependency-free website for Out-n-About Bar and Music Lounge in Dundee, Florida.

## Live site

https://prithiraj.github.io/bar-n-music-lounge/

## Structure

- `site/index.html` — home
- `site/events/index.html` — researched upcoming events
- `site/visit/index.html` — address, directions, currently listed hours
- `site/assets/styles.css` — responsive design system
- `.github/workflows/pages.yml` — GitHub Pages deployment

## Content maintenance

Time-sensitive business information changes. Before updating events, hours, menu items, or phone details, verify them against an owner-controlled or authoritative source. The phone number is intentionally omitted because current public directories conflict.
